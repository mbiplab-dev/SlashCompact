How to read this

2D image: the original satellite photograph.

3D terrain: the same photograph placed over the calculated height surface. Buildings and trees should rise above the ground.

Spikes: usually mean abrupt estimated-height changes or a noisy ground file. Lower the visual scale to inspect the real shape without exaggeration.
